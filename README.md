# Professional Portfolio 2026 - Mr. Jaturong Songpakdee

Promotion Documentation: Technical Officer Level 6 to Level 7.
Department: Electrical Power Production (ผรผ.กสฟ.น2), Provincial Electricity Authority (PEA).

## Project Overview
A modern, single-page infographic website showcasing the annual achievements (2025-2026) of Mr. Jaturong Songpakdee. Designed with premium aesthetics, responsive layouts, and PEA branding (Purple & Orange).

## Key Achievements
- **Communication Cable Survey**: Professional organization and surveying of cables on PEA poles.
- **Electrical System Improvement**: Upgrading and maintaining high-voltage distribution networks.
- **EV Infrastructure**: Expert consultation and installation of EV Stations and Home Charging systems.

## Tech Stack
- **HTML5 & CSS3**: Custom grid systems and glassmorphism UI.
- **AOS (Animate On Scroll)**: Smooth visual transitions.
- **Google Fonts**: Kanit & Sarabun for professional Thai/English typography.

## Project Structure
- `Mark 2/portfolio/index.html`: Main landing page.
- `Mark 2/portfolio/style.css`: Custom design tokens and styles.
- `Mark 2/portfolio/images/`: Optimized assets for the portfolio sections.

## How to Deploy
1. Open terminal and run `git push origin main`.
2. Host the `Mark 2/portfolio` folder on GitHub Pages for a live URL.
